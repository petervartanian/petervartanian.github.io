# Catalog of 1+2+3

Published at https://petervartanian.xyz/backdrive/. All AI and Back\Drive use the same incident, capability, and evaluation records; Back\Drive filters the catalog to robotics.

This is a static application. Serve this directory over HTTP or open `index.html` directly. The app requires no account, build step, or external font service.

Fourteen reported incidents and one illustrative construction scenario are linked to proposed capability and evaluation mappings. Sources are attached to the records and listed in `sources/catalogue.json`. RoboHarm aggregates come from published benchmark results. Interventions and pilots are proposals; none of these pilots has been run.

Logo assets retain the supplied artwork and proportions, with the requested transparency and color adjustments.
