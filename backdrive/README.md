# Catalog of 1+2+3

Published at https://petervartanian.xyz/backdrive/. All AI and Back\Drive use the same incident, capability, and evaluation records; Back\Drive filters the catalog to robotics.

This is a static application. Serve this directory over HTTP or open `index.html` directly. The app requires no account, build step, or external font service.

Fourteen reported incidents and one illustrative construction scenario are linked to proposed capability and evaluation mappings. Sources are attached to the records and listed in `sources/catalogue.json`. RoboHarm aggregates come from published benchmark results. Interventions remain proposals. The Sage Plant’s featured entry contains its proposed Dusty Robotics and Derutu cases, supplied September 28, 2026. No field results are recorded. MIT participation and scope remain to be agreed; the other pilots are illustrative examples.

Logo assets retain the supplied artwork and proportions, with the requested transparency and color adjustments.

The two Sage Plant cases show the decision, baseline, safeguards, observations and draft decision criteria. The top-right note contains source attribution, reported budgets, scope questions and the shared observation fields. Original correspondence, the private deck and exact site addresses are not published. Open `?pilot=dusty` or `?pilot=derutu` to link directly to a case.
